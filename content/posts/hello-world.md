博客终于搭起来了。

用的是 **Hugo + PaperMod**，托管在 GitHub Pages 上。选这套的原因很简单：

- Hugo 是静态站点生成器，编译一次就是纯 HTML，打开速度极快
- PaperMod 主题自带暗色模式、搜索、归档，功能够用又不过度
- GitHub Pages 免费，推送代码自动构建部署

## 以后打算写什么

| 方向 | 内容 |
|---|---|
| 工具开发 | 自己写的小脚本、小工具的实现思路 |
| 踩坑记录 | 遇到问题怎么解决的，免得下次再踩 |
| 技术笔记 | 平时看的东西整理一下 |

## 写一篇新文章

```bash
hugo new content posts/文章名.md
```

然后在编辑器里改内容，把 `draft: false` 打开，提交推送就发布了。

就这些，先开个头。
